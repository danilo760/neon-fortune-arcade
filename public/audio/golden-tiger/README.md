# Golden Tiger hybrid sample pack

The runtime supports original/licensed OGG or WAV samples at these paths. Missing files automatically fall back to the procedural WebAudio score; no third-party audio is bundled.

- `spin-start.ogg`
- `reel-stop-1.ogg`
- `reel-stop-2.ogg`
- `reel-stop-3.ogg`
- `anticipation.ogg`
- `symbol-lock.ogg`
- `big-win-stinger.ogg`
- `coin-drop.ogg`

Use only audio recorded/commissioned for this project or otherwise licensed for distribution.
